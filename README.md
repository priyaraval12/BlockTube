🎥 BlockTube

BlockTube is a decentralized video-sharing platform built on the Polygon blockchain. It enables users to upload, share, and watch videos securely using IPFS & Filecoin for storage, and The Graph for indexing — all while keeping user privacy intact.

---
 🔑 Key Features

- Decentralized video hosting (via Filecoin & IPFS)
- On-chain publishing powered by Polygon
- Privacy-first design — no centralized servers
- Fast, low-cost transactions using Polygon PoS
- Smart contracts deployed using Hardhat
- Data indexed with The Graph Protocol

---

📦 Tech Stack

- Polygon (Mumbai Testnet / Mainnet)
- Solidity + Hardhat
- IPFS & Filecoin (via web3.storage or Lighthouse)
- The Graph for indexing video data
- React + Ethers.js for frontend
